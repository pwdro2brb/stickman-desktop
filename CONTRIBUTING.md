# Contributing

Thank you for considering a contribution.

## Setup

```bash
python -m pip install -e .
python -m pip install pytest
python -m pytest
```

## Pull requests

- Keep changes focused.
- Add or update tests for platform-independent logic.
- Explain Windows-specific behavior and manual test steps.
- Do not add arbitrary shell execution.
- Do not weaken the application allowlist.
- Do not include copyrighted characters, artwork, names or story assets.
- Use original assets or assets with a clearly compatible license.

## Issues

Include:

- Windows version;
- Python version;
- number and arrangement of monitors;
- exact reproduction steps;
- expected and actual behavior;
- traceback, when available.
